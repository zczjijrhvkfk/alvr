## 🕹️ Overview

ALVR streams SteamVR content wirelessly to Meta Quest, Pico, and other Android-based VR headsets over Wi-Fi using an open protocol with low-latency codecs.

Whether you're a newcomer or a veteran, ALVR provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Open Source** | Fully open protocol with active community development |
| **Quest Compatible** | Works with Meta Quest 1, 2, 3, and Pro headsets |
| **Codec Options** | H.264, HEVC, and AV1 encoding with tunable bitrate |
| **Foveated Encoding** | Optional fixed foveated rendering for bandwidth savings |
